News Classifier API

Production-ready machine learning API for classifying news articles into categories with high accuracy.

API Documentation Wiki GitHub

API Overview

Authentication

Protected endpoints require an API key in the X-API-Key header.

# Example request with authentication curl -X POST "http://localhost:7860/predict" \ -H "X-API-Key: your_api_key_here" \ -H "Content-Type: application/json" \ -d '{"title": "Breaking tech news"}'

Rate Limits

Public Endpoints 100 requests/minute
/predict 30 requests/minute
/predict/batch 10 requests/minute

When rate limit is exceeded, the API returns HTTP 429 with a Retry-After header.

Endpoints

GET /info

Get model information including version, loaded status, and available categories.

100/min
POST /predict Auth Required

Classify a single news article title. Returns predicted category and confidence score.

30/min
POST /predict/batch Auth Required

Process up to 100 news titles in a single request. Ideal for bulk classification tasks with better performance than individual requests.

10/min
GET /metrics

Prometheus metrics endpoint for monitoring API performance, request rates, and prediction statistics.

No Limit
GET /docs

Interactive Swagger/OpenAPI documentation with request/response schemas and testing interface.

No Limit
